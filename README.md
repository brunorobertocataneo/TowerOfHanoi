# Torre de Hanói em C#

Implementação da Torre de Hanói que representa os pinos com pilhas e registra a quantidade de movimentos.

A lógica do quebra-cabeça está em [HanoiTower.cs](HanoiTower.cs) e a entrada do programa em [Program.cs](Program.cs).

## Executar

Com o SDK do .NET 9 instalado, execute na raiz do repositório:

```bash
dotnet run --project TowerOfHanoi.csproj
```
